Discord
Presentation & transport

Là giao diện Trung sử dụng để trò chuyện với Basic & Logic. Discord giữ channel, thread và message ở cấp nền tảng, rồi chuyển sự kiện tới Hermes Gateway.

  • Nhận yêu cầu và hiển thị câu trả lời, file, ảnh, audio.
  • Phân tách ngữ cảnh qua server/channel/thread.
  • Không phải knowledge base, runtime hay source of truth của code.

Hermes Agent
Orchestrator & runtime

Là trung tâm điều phối: nhận message, ghép context, gọi model, quyết định công cụ, thực thi vòng lặp và gửi kết quả về Discord. “Basic & Logic” là tên trợ lý; Hermes là nền tảng bên dưới.

  • Gateway và session routing.
  • Agent/tool-calling loop, context compression và verification.
  • Terminal, file, code execution, web, vision, memory, cron, delegation.
  • Native MCP client kết nối dịch vụ ngoài.
  • Skills lưu quy trình tái sử dụng.

LLM
Reasoning engine

Model phân tích yêu cầu, tạo nội dung và đề xuất tool call. Hermes tách agent logic khỏi provider để có thể thay model hoặc thiết lập fallback mà không đổi toàn bộ kiến trúc.

  • Không tự có quyền host; quyền đến từ tool Hermes cung cấp.
  • Không phải kho lưu trữ dài hạn.
  • Kết quả quan trọng phải được kiểm chứng bằng tool output.

MCP
Integration protocol

Model Context Protocol là chuẩn adapter giữa Hermes và các dịch vụ. Hermes kết nối MCP server lúc khởi động, discovery tools, rồi đăng ký chúng như công cụ hạng nhất.

  • Notion MCP dùng stdio qua npx.
  • CFMan MCP dùng remote HTTP.
  • Tool thường có tên mcp_<server>_<tool>.
  • MCP là giao thức kết nối, không phải database.

Notion
Curated project knowledge

Là kho project memory và knowledge có human review. Notion phù hợp với quyết định, quy trình, summary đã lọc và facts đang chờ phê duyệt.

  • Databases: Projects, Decisions, Knowledge, Processes, Conversation Archive, Memory Inbox.
  • Chỉ record Approved mới đủ điều kiện đi tiếp sang Honcho.
  • Không nên chứa raw export, bí mật hoặc dữ liệu nghiệp vụ chi tiết theo mặc định.
Honcho
Long-term user memory

Lưu và suy diễn representation dài hạn về user/peer: preference, cách xưng hô, constraint ổn định, patterns có ích xuyên phiên.

  • API nhận và truy vấn memory.
  • Deriver xử lý observations/conclusions/representation.
  • PostgreSQL lưu dữ liệu bền vững; Redis hỗ trợ runtime.
  • Không thay Notion, Git hay kho tài liệu gốc.

Host
Execution infrastructure

Máy Linux là nơi code, services, databases, artifacts và tunnel chạy thật. Hermes thao tác với host qua terminal/file/process tools.

  • Chứa Hermes, Honcho, repositories, artifacts, PostgreSQL, Redis, cloudflared.
  • Dịch vụ backend nên bind localhost khi không cần truy cập trực tiếp từ mạng.
  • Filesystem/repository mới phản ánh artifact và code hiện tại.

Claude Code
Proposed coding worker

Có thể tham gia như worker chuyên trách đọc code, sửa repository, chạy test và trả handoff. Không nên trở thành orchestrator thứ hai cùng quyền trên mọi hệ thống.

  • Làm việc trong git worktree/task scope riêng.
  • Đọc CLAUDE.md, AGENTS.md, project state.
  • Trả diff, test results, caveats và next action cho Hermes.

Thuật ngữ bằng ngôn ngữ đơn giản

Glossary

Tìm theo tiếng Anh hoặc tiếng Việt. Mỗi thuật ngữ giải thích theo vai trò cụ thể trong hệ thống này.

AAgent
Chương trình dùng LLM để suy luận theo vòng lặp, gọi công cụ và theo đuổi một mục tiêu; không chỉ sinh một câu trả lời.
AAPI
Giao diện lập trình để hai hệ thống trao đổi dữ liệu hoặc yêu cầu. Honcho API tại localhost là một ví dụ.
AApproval
Điểm cần con người hoặc policy cho phép trước khi thực hiện hành động có rủi ro.
AArtifact
Sản phẩm đầu ra có thể bàn giao: file HTML, báo cáo, tài liệu, build hoặc dataset.
AAudit log
Nhật ký ai/agent đã làm gì, lúc nào, với mục tiêu và kết quả nào.
BBind address
Địa chỉ mạng mà một service lắng nghe. 127.0.0.1 chỉ cho phép truy cập từ chính host; 0.0.0.0 lắng nghe trên mọi interface.
CCache
Dữ liệu tạm để tăng tốc; có thể tái tạo và không nên là nguồn chân lý duy nhất.
CCFMan
Control plane quản lý Cloudflare account, zone, tunnel, route, publication và command execution cho hệ thống này.
CClaude Code
Coding agent chạy trong terminal, phù hợp đọc repository, sửa code và chạy test. Trong thiết kế này nó là worker dưới Hermes.
CCloudflare Edge
Hạ tầng public nhận HTTPS request từ Internet trước khi chuyển qua tunnel về host.
CCloudflare Tunnel
Kết nối outbound từ host tới Cloudflare, cho phép public service local mà không cần mở trực tiếp cổng inbound.
CCommand Agent
Thành phần đặc quyền nhận yêu cầu thực thi script/command có kiểm soát trên host từ CFMan.
CContext
Thông tin model nhận cho lượt xử lý hiện tại: message, lịch sử, memory, project rules và tool results.
CControlled write
Quyền ghi chỉ thông qua tool/policy có scope, validation và audit; không phải quyền sửa tùy ý.
CCron job
Tác vụ chạy theo lịch và có thể tồn tại độc lập với phiên chat hiện tại.
DDatabase
Hệ thống lưu và truy vấn dữ liệu có cấu trúc. PostgreSQL là database bền vững; Redis chủ yếu là cache/transient state.
DDelegation
Hermes giao một phần việc cho subagent hoặc coding worker với context và scope riêng.
DDeriver
Process Honcho phân tích observations để tạo conclusions hoặc representation dài hạn về peer.
GGateway
Lớp kết nối nền tảng nhắn tin với agent runtime: nhận Discord message, route session và gửi phản hồi.
GGit
Hệ thống version control lưu lịch sử code/diff và hỗ trợ rollback, review, branch, worktree.
GGlossary
Danh mục thuật ngữ và định nghĩa dùng chung để tránh hiểu khác nhau giữa người, Hermes và Claude Code.
HHandoff
Gói chuyển giao task/result giữa hai agent: mục tiêu, scope, diff, test evidence, caveats và next steps.
HHermes Agent
Runtime/orchestrator kết nối model, tools, sessions, memory, skills và messaging platforms. Không phải tên hiển thị của trợ lý.
HHoncho
Hệ thống long-term memory và user representation; lưu facts ổn định, không thay knowledge base hay repository.
HHost
Máy Linux thực sự chạy Hermes, Honcho, database, files, services và cloudflared.
HHuman review
Bước Trung xem và duyệt nội dung trước khi nó trở thành decision/knowledge chính thức hoặc memory dài hạn.
IIngress route
Quy tắc ánh xạ hostname/path public qua tunnel tới một local service.
LLLM
Large Language Model; engine suy luận và sinh ngôn ngữ, nhưng chỉ có quyền hành động qua tools mà runtime cấp.
LLocalhost / 127.0.0.1
Địa chỉ loopback chỉ truy cập được từ chính máy, dùng để giữ backend services không public trực tiếp.
MMCP

MMemory candidate

NNotion MCP

KIẾN TRÚC HIỆN TẠI

1. Discord
- Là giao diện chat và message transport.
- Người dùng gửi yêu cầu qua Discord.
- Discord không phải source of truth cho code, knowledge hoặc memory.

2. Hermes Agent
- Là runtime/orchestrator trung tâm.
- Chạy Gateway dưới systemd user service.
- Nhận message từ Discord, quản lý session/thread/user context.
- Chọn model/provider; gọi terminal, filesystem, code execution, memory, session search, cron, delegation và MCP tools.
- Model/provider quan sát tại thời điểm kiểm tra: claude-opus-4-8 / Anthropic.
- Hermes có skills dạng SKILL.md.
- Session store nằm trong /root/.hermes; source tại /root/tools/hermes-agent.

3. MCP
- Hermes kết nối Notion MCP qua npx -y @notionhq/notion-mcp-server.
- Hermes kết nối CFMan MCP qua remote HTTP endpoint.
- MCP tools được discovery và đăng ký với prefix mcp_<server>_<tool>.

4. Notion
- Là project/knowledge repository có human review.
- Các database: Projects, Decisions, Knowledge, Processes, Conversation Archive và Memory Inbox.
- Nhận metadata, summaries, decisions, knowledge và candidates đã lọc.
- Raw transcript/export, tài liệu pháp lý gốc, dữ liệu HR/customer và detailed financial data giữ local/server.
- Chỉ facts có trạng thái Approved mới được đồng bộ sang Honcho.

5. Honcho
- Là long-term memory và user representation layer.
- Chỉ lưu facts ngắn, ổn định và đã được phê duyệt.
- Không lưu toàn bộ transcript, source code hoặc tài liệu gốc.
- API: 127.0.0.1:8000; MCP/worker: 127.0.0.1:8787.
- PostgreSQL: 127.0.0.1:5432; Redis: 127.0.0.1:6379.
- Deriver process xử lý/suy diễn memory.

6. Host
- Là execution and persistence infrastructure.
- Chứa Hermes, Honcho, repositories, artifacts, PostgreSQL, Redis, cloudflared và services nội bộ.
- Backend services nên bind localhost.
- Không expose PostgreSQL, Redis, Honcho API hoặc command-agent trực tiếp ra Internet.

7. CFMan / Cloudflare
- Tunnel “Trung Truong's AI Agent”, ID a60659cf, zone basicnlogic.com.
- cloudflared chạy trên host; CFMan publish HTTP service localhost ra subdomain HTTPS.
- CFMan không thay thế application authentication.
- Command-agent tại 127.0.0.1:47831 là privileged execution surface.
- Publication, tunnel changes và command-agent phải được kiểm soát/audit.

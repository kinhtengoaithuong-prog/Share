Target repos (profiles)

Mỗi profile = 1 repo GitHub đích + 1 token fine-grained riêng (least-privilege — token lộ chỉ đụng đúng 1 repo). Khi publish một link, bạn bắt buộc chọn profile; link nhớ nó thuộc profile nào để publish/xóa/sync route đúng chỗ. Ví dụ: GitHub Pages công khai cho tài liệu chia sẻ · Finan riêng (private.basicnlogic.com) cho BCQT/staff cost.

Tiện ích — Lấy GitHub Token

Lấy token nhanh: mở link tạo Fine-grained Personal Access Token, chọn repo cần publish, rồi cấp quyền Repository permissions → Contents → Read and write. GitHub chỉ hiện token 1 lần, nên copy ngay vào ô token của tool.

Snapshot toàn bộ trạng thái tool

Export/Import toàn bộ trạng thái tool: config GitHub + token, danh sách links, trường tùy chỉnh, danh sách dự án, và tùy chọn giao diện (theme, view, splitter). Dùng để backup hoặc bê nguyên tool sang máy khác. ⚠ V8: token của các target KHÔNG được export (an toàn PAT) — sau khi import cần nhập lại token ở tab Cấu hình.

Danh sách links (tái sử dụng)

Export riêng danh sách links (kèm dự án, product, trạng thái, trường tùy chỉnh) ra file để chia sẻ hoặc nạp vào tool khác. Không chứa token/config. Khi import, bạn chọn gộp thêm (merge) hoặc thay thế toàn bộ danh sách hiện tại.

Reset

Xóa toàn bộ config + token + history khỏi trình duyệt này. Không ảnh hưởng file đã publish trên GitHub.
